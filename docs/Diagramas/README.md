# Diagramas do Synple

- **[ENTREGA DEFINITIVA](ENTREGA_DEFINITIVA/README.md):** pacote escolhido para a entrega, com 33 fontes e 33 imagens SVG, separado por tipo no índice.
- [Versões anteriores](VERSOES_ANTERIORES/README.md): cinco fontes antigas preservadas como histórico.
- [Catálogo visual completo](Diagramas_Casos_de_Uso.md): imagens da entrega definitiva incorporadas para consulta.

As pastas `fontes` contêm arquivos editáveis; `renderizados` contém as imagens para visualizar. Para enviar o pacote completo, utilize a pasta `ENTREGA_DEFINITIVA` com seu README e manifesto. Os dicionários e requisitos que acompanham os modelos estão vinculados no índice.
