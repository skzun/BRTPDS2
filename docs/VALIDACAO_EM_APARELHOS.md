| Editar reunião futura | Dados persistidos e convidados reconfirmam | Pendente |
| Convidado/presença fora do período | API nega e dados permanecem inalterados | Pendente |
| Presença biométrica, código e gestor | Ator/alvo/horário corretos; código expira | Pendente |
| Anexo PDF/imagem/TXT | Arquivo original baixado por convidado, negado a estranho | Pendente |
| Lista de presença em PDF | Nomes/acentos/horários legíveis; link expirado negado | Pendente |
| Votação | Somente presente vota, altera antes de fechar e não altera depois | Pendente |
| Ata | Presidente cria, presentes aprovam/reprovam; versão antiga negada | Pendente |
| Meu relatório | Apenas reuniões com entrada do titular da sessão | Pendente |
